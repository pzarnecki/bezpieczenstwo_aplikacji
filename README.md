## O projekcie
Repozytorium zawiera materiały dydaktyczne, interaktywne prezentacje HTML oraz skrypty akademickie do przedmiotu **Bezpieczeństwo Aplikacji** (Informatyka, studia II stopnia – magisterskie).

Prezentacje działają w 100% lokalnie i offline w każdej nowoczesnej przeglądarce, bez zewnętrznych zależności CDN czy bibliotek zewnętrznych.

## Sterowanie w prezentacji
* `→` / `Spacja` / `PageDown`: Następny slajd
* `←` / `PageUp`: Poprzedni slajd
* `↓`: Płynne przewinięcie w dół do szczegółów (drill-down / Lista Grozy)
* `↑`: Powrót na górę slajdu
* `F`: Tryb pełnoekranowy (Fullscreen)
* `O`: Siatka podglądu wszystkich slajdów (Overview modal)
